# 四级自由词库

- `word-atlas.json`：去重后的 4,445 个词条，保留合并前释义、读音与来源编号。
- `source-import.json`：4,449 条原始记录的去重说明和合并明细。
- `media-provenance.json`：逐词图片、录音和例句来源。
- `image-generation-prompts.json`：内置生图新增插画的提示词。

词表唯一来源：`cet4-source/Words_all.md`。没有固定天数或每日背诵分配。复用媒体与例句来自 designfuchen/word-atlas，按 CC BY 4.0 保留署名；用户提供的词表来源单独标记。详见根目录 README.md、CONTENT_LICENSE.md。
