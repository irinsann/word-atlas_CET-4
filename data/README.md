# 四级自由词库

- `word-atlas.json`：校订与合并后的 4,843 个词条，含学习范围、释义、读音与原始来源记录。
- `vocabulary-review.json`：逐词范围与理由、拼写校订和合并 ID 别名。
- `vocabulary-audit-reference.json`：2016 版官方大纲对照证据；不将第三方词书当成官方分类。
- `source-import.json`：4,449 条原始记录的去重说明和合并明细。
- `media-provenance.json`：逐词图片、录音和例句来源。
- `image-generation-prompts.json`：内置生图新增插画的提示词。

词表来自 `cet4-source/Words_all.md` 和保存有来源校验值的第三方重点词表，按考试大纲核对范围。没有固定天数或每日背诵分配。复用媒体与例句来自 designfuchen/word-atlas，按 CC BY 4.0 保留署名；用户提供的词表来源单独标记。详见根目录 README.md、CONTENT_LICENSE.md。
