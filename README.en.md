# Word Atlas · CET-4 edition

A local adaptation of designfuchen/word-atlas using the supplied 2,607-word CET-4 list and a 14-day learn/review schedule. Run `npm ci` then `npm run dev`, or double-click `start-cet4.cmd` on Windows. Open http://127.0.0.1:5194/.

See README.md for the schedule, source attribution, image provenance, speech-synthesis fallback and build commands. Original code: MIT. Reused original content: CC BY 4.0. Original author: yangleiocx3; source repository: https://github.com/designfuchen/word-atlas.
